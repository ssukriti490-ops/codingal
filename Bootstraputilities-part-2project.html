SPINNER

Bootstrap includes several classes for creating various styles of "spinner" to display the loading projects. These classes are built with HTML and CSS, so on JavaScript is required to create them .Using the Bootstrap classes,we can also change the appearance , size,andnplacement of the spinners. We can create a bordered spinner using the .spinner-border class inside .div element.
